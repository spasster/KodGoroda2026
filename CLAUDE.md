# Дашборд мониторинга стажировок

HR-дашборд для кейса МГТС: ежемесячные анкеты стажёров и наставников → сигналы по каждой паре → экран «с кем поговорить».

- Контракт данных, API и сигналов: `docs/contract.md`. Код следует ему; если меняешь контракт, правишь все стороны в одном изменении.
- Дизайн: `docs/design/v2.md` (стиль МГТС, раздел «Запрещено»). Старый `system.md` больше не эталон.
- Анкета и пороги вынесены в `survey/`. Под данные финала меняются только эти файлы и `survey/import_map.json`.

## Правила

- Интерфейс, ошибки API и тексты сигналов на русском. Пишем как человек: короткие предложения, конкретика и цифры, глаголы вместо отглагольных существительных. Без «не просто X, а Y», без эмодзи в интерфейсе, без жирного посреди фразы, без тире как связки. Регистр как в предложении.
- Оценки считаем формулами, модель читает только текст. Любой вывод модели идёт с цитатой, прошедшей `verify_quote`.
- ИИ ничего не решает за HR: сигнал предлагает разговор, HR отмечает «проблема подтвердилась» или «проблемы нет».
- Python 3.13 через uv, зависимости в `backend/pyproject.toml`. Фронт: pnpm, TypeScript strict.
- Всё должно запускаться без интернета, без CDN. Шрифты МГТС (MTS Wide, Compact, Text, те же файлы, что на studchamp.mgts.ru) лежат в `frontend/src/styles/fonts`, в git их нет: `make fonts`.
- Не коммитить `.env`, базу SQLite, `node_modules`.

## Команды

- `make dev` — бэкенд на :8000 и фронт на :5173.
- `make test` — тесты бэкенда и проверка типов фронта.
- `make data` — пересобрать `data/sample`.
- `make reset` — очистить базу и загрузить `data/sample`.
- `make up` — всё в Docker на :8080.
