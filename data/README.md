# Тестовый набор

Имитация выгрузки анкет МГТС: 5 пар «стажёр и наставник», месяцы 1–5 в таблицах, 6-й месяц отправляем вживую на демо. Формат таблиц описан в `docs/contract.md`, раздел «Формат Excel». Месяц 1 приходится на июнь 2026, анкеты заполнены в последнюю неделю каждого месяца.

## Сценарии

| Пара | Сценарий | Что в данных | Что должно сработать |
|---|---|---|---|
| P-01 | ровная пара | обе стороны 4,4–4,8, спокойные комментарии по делу | ничего, это контроль |
| P-02 | выгорание | стажёр 4,6 → 4,4 → 3,8 → 3,0, за 5-й месяц анкеты нет; комментарии сжимаются до «нормально», потом пусто | во 2-м месяце текст о переработках при оценке 4,4; спад и разрыв 1,75 в 4-м; молчание в 3–5-м |
| P-03 | напряжение с наставником | стажёр 3,0–3,8, «помощь наставника» 2, пишет, что наставник не отвечает; наставник 4,5–4,75 и «всё хорошо» | разрыв со 2-го месяца, с 4-го высокий |
| P-04 | нет задач | стажёр ставит 3,8–4,2, а пишет «задач пока почти нет»; наставник доволен | текст против оценки во 2–5-м месяцах, видно только по тексту |
| P-05 | наставник недоволен | стажёр 4,6–4,8, наставник 4,0 → 3,5 → 3,0 → 2,5 → 2,0 | обратный разрыв со 2-го месяца, спад наставника с 3-го |

В `sample-12` к ним добавлены пять благополучных пар с шумом в оценках и два слабых сценария. У P-07 разрыв дорастает до 1,1 только в 5-м месяце. У P-10 в 4-м месяце развёрнутый комментарий сменяется строкой «Всё по плану, без новостей». Обе пары жёлтые. У P-09 стажёр пишет по одному-два слова, у P-11 наставник вообще не пишет комментариев: это норма для этих людей, сигналов быть не должно.

## Пересобрать

```sh
uv run data/generate.py --out data/sample --pairs 5 --months 5 --seed 7
uv run data/expected.py data/sample
uv run data/generate.py --out data/sample-12 --pairs 12 --months 5 --seed 7
uv run data/expected.py data/sample-12
```

При одном seed файлы совпадают побайтно. `expected.py` выходит с кодом 1, если у контрольной пары нашёлся хоть один сигнал.

Комментарии и оценки лежат в `scenarios.py`. У каждого комментария есть ручная разметка: тональность, темы и цитата. Новый комментарий без разметки `expected.py` не пропустит.

## Что в truth.json

- `signals` должны быть у бэкенда при любом прочтении правил контракта.
- `optional` зависят от прочтения, `fires_when` говорит, от какого. Варианты прочтений описаны в `readings`.
- Сигналов вне `signals` и `optional` быть не должно.
- `text_analysis: true` значит, что сигнал держится на разборе текста. Если анализатор `rules` его не находит, надо докрутить словарь, данные тут ни при чём.
- `near_threshold` перечисляет сравнения, которые прошли близко к порогу. Сейчас это спад наставника P-05: 0,125 при пороге 0,12, если требовать падения на порог в каждом из двух месяцев.
- `comments` содержит разметку каждого комментария, на ней можно проверять анализатор.
- `pairs[].cells` и `pairs[].status` пригодятся для макетов.

## Живое демо

```sh
data/send_demo.sh data/sample/demo/intern_S-01_m6.json
data/send_demo.sh data/sample/demo/mentor_M-01_m6.json
```

Первая анкета: стажёр ровной пары ставит 2,6 и пишет «Третью неделю сижу без задач». P-01 краснеет: резкий спад 4,6 → 2,6 и молчание наставника за 6-й месяц. Вторая анкета: наставник ставит 4,75. Молчание уходит, появляется разрыв 2,15 балла.

Остальные файлы в `demo/` дают по одной анкете 6-го месяца на каждую пару в духе её сценария. Что должно появиться после каждого файла, записано в `truth.json` → `demo.steps`.

По умолчанию скрипт шлёт на `http://localhost:8000`. Для Docker: `API=http://localhost:8080 data/send_demo.sh ...`. Можно передать несколько файлов сразу.

До демо проверить у бэкенда два места, иначе картинка поплывёт:

- После анкеты S-01 у других пар не должно появиться молчание за 6-й месяц. Оно появится, если считать месяц прошедшим, когда его заполнила хотя бы одна другая пара.
- Активные месяцы отсчитываются от последнего месяца самой пары. Если считать от последнего месяца всего набора, после анкеты S-01 пары P-02 и P-04 станут жёлтыми.
