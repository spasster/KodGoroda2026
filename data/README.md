# Тестовый набор

Имитация выгрузки анкет МГТС: 5 пар «стажёр и наставник», месяцы 1–5 в таблицах, 6-й месяц отправляем вживую на демо. Формат таблиц описан в `docs/contract.md`, раздел «Формат Excel». Месяц 1 приходится на июнь 2026, анкеты заполнены в последнюю неделю каждого месяца.

## Сценарии

| Пара | Сценарий | Что в данных | Что должно сработать |
|---|---|---|---|
| P-01 | ровная пара | обе стороны 4,4–4,8, спокойные комментарии по делу | ничего, это контроль |
| P-02 | выгорание | стажёр 4,6 → 4,4 → 3,8 → 3,0, за 5-й месяц анкеты нет; комментарии сжимаются до «нормально», потом пусто | во 2-м месяце текст о переработках при оценке 4,4; спад в 3-м и 4-м, разрыв 1,8 в 4-м; молчание в 3–5-м; в 4–5-м наставник ставит 4,5–4,75, а пишет, что стажёр стал медленнее; в 4-м стажёр ставит 2 за один из вопросов (низкая оценка по вопросу) |
| P-03 | напряжение с наставником | стажёр 3,0–3,8, «помощь наставника» 2, пишет, что наставник не отвечает; наставник 4,5–4,75 и «всё хорошо» | разрыв со 2-го месяца, с 4-го высокий; низкая оценка по вопросу «помощь наставника» в 3–5-м месяцах |
| P-04 | нет задач | стажёр ставит 3,8–4,2, а пишет «задач пока почти нет»; наставник доволен | текст против оценки во 2–5-м месяцах, видно только по тексту |
| P-05 | наставник недоволен | стажёр 4,6–4,8, наставник 4,0 → 3,5 → 3,0 → 2,5 → 2,0 | обратный разрыв со 2-го месяца, спад наставника с 3-го; низкие оценки наставника по вопросам в 3–5-м (с 4-го высокая важность) |

В `sample-12` к ним добавлены пять благополучных пар с шумом в оценках и два слабых сценария. У P-07 разрыв дорастает до 1,1 только в 5-м месяце. У P-10 в 4-м месяце развёрнутый комментарий сменяется строкой «Всё по плану, без новостей». Обе пары в статусе «Присмотреться». У P-09 стажёр пишет по одному-два слова, у P-11 наставник вообще не пишет комментариев: это норма для этих людей, сигналов быть не должно.

## Пересобрать

```sh
uv run data/generate.py --out data/sample --pairs 5 --months 5 --seed 7
uv run data/expected.py data/sample
uv run data/generate.py --out data/sample-12 --pairs 12 --months 5 --seed 7
uv run data/expected.py data/sample-12
```

При одном seed файлы совпадают побайтно. Месячные сигналы (`signals`) склеиваются в ситуации: одна на тип и роль у пары. На `sample` это 12 ситуаций, 11 активных: P-02 шесть (разрыв, спад, молчание, низкая оценка, текст наставника и текст стажёра из 2-го месяца, он уже не активен), P-03 две (разрыв со 2-го месяца, низкая оценка), P-04 одна (текст против оценки), P-05 три (обратный разрыв, спад и низкие оценки наставника), P-01 ничего. `expected.py` выходит с кодом 1, если у контрольной пары нашёлся хоть один сигнал.

Комментарии и оценки лежат в `scenarios.py`. У каждого комментария есть ручная разметка: тональность, темы и цитата. Новый комментарий без разметки `expected.py` не пропустит.

## Что в truth.json

- `pairs[].situations` — ситуации у пары: ключ без месяца, `months`, `since_month`, важность, `active`. `test_sample_truth.py` сверяет их с `/api/signals`.
- `signals` — месячные сигналы, посчитаны по прочтениям из `docs/contract.md`, раздел «Как читать условия». Бэкенд должен дать ровно их. Это проверяет `backend/tests/test_sample_truth.py`.
- `optional` пуст. Он нужен, только если вернуть в `expected.py` перебор всех прочтений: тогда там окажутся сигналы, которые зависят от прочтения, а `fires_when` скажет, от какого.
- `readings` перечисляет варианты прочтений, `primary` из контракта.
- `text_analysis: true` значит, что сигнал держится на разборе текста. Если анализатор `rules` его не находит, надо докрутить словарь, данные тут ни при чём.
- `near_threshold` перечисляет сравнения, которые прошли близко к порогу. В `sample` таких нет. В `sample-12` это спад стажёра P-07 с 1-го по 3-й месяц: 0,10 при пороге 0,12, сигнала нет.
- `comments` содержит разметку каждого комментария, на ней можно проверять анализатор.
- `pairs[].cells` и `pairs[].status` пригодятся для макетов.

## Живое демо

```sh
data/send_demo.sh data/sample/demo/intern_S-01_m6.json
data/send_demo.sh data/sample/demo/mentor_M-01_m6.json
```

Первая анкета: стажёр ровной пары ставит 2,6 и пишет «Третью неделю сижу без задач». P-01 переходит в «Пора поговорить»: резкий спад 4,6 → 2,6, низкая оценка по вопросу и сигнал «Наставник ещё не прислал анкету» за 6-й месяц. Вторая анкета: наставник ставит 4,75, на экране 4,8. Молчание уходит, появляется разрыв 2,2 балла.

Остальные файлы в `demo/` дают по одной анкете 6-го месяца на каждую пару в духе её сценария. Что должно появиться после каждого файла, записано в `truth.json` → `demo.steps` (месячные сигналы; в API это ситуации: новые или с новым месяцем).

По умолчанию скрипт шлёт на `http://localhost:8000`. Для Docker: `API=http://localhost:8080 data/send_demo.sh ...`. Можно передать несколько файлов сразу.

До демо проверить у бэкенда два места, иначе картинка поплывёт:

- После анкеты S-01 у других пар не должно появиться молчание за 6-й месяц. Оно появится, если считать месяц прошедшим, когда его заполнила хотя бы одна другая пара.
- Активные месяцы отсчитываются от последнего месяца самой пары. Если считать от последнего месяца всего набора, после анкеты S-01 пары P-02 и P-04 перейдут в «Присмотреться».
