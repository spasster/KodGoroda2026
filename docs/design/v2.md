# Дизайн v2: стиль МГТС, меньше слов

Заменяет `system.md` во всём, что касается внешнего вида и текстов. Логика данных, API и сигналов не меняется.

Первая версия получилась перегруженной: подписи под каждой кнопкой, пояснения под каждым заголовком, бейджи, цепочки чисел, легенды. Вторая версия делает наоборот: экран отвечает на один вопрос, слова только там, где данные сами не говорят.

## Стиль

Как сайт чемпионата МГТС (studchamp.mgts.ru), дизайн-система Granat группы МТС.

- Фон светло-серый `--bg` (#F2F3F7), содержимое на белых карточках `--surface`, радиус `--r-card` (24px), тень `--shadow-low`, внутренний отступ 24–32px. Тёмная тема на графите.
- Синий МГТС `--brand` (#008AE0) только для того, на что нажимают: кнопки, ссылки, активный пункт меню, выбранное значение, метка «новое».
- Статус пары и месяца: цветная точка 8–10px и мягкая заливка ячейки (`--risk-wash`, `--watch-wash`, `--ok-wash`). Текст всегда `--text-1`, никогда не красный.
  - `risk` → «Пора поговорить», оранжевый `--risk`
  - `watch` → «Присмотреться», жёлтый `--watch`
  - `ok` → «Всё ровно», зелёный `--ok`
- Шрифты (токены в `src/styles/tokens.css`): `--font-wide` (MTS Wide) для заголовков страниц и крупных чисел; `--font` (MTS Compact) для интерфейса, таблиц, кнопок, цифр с `font-variant-numeric: tabular-nums`; `--font-text` (MTS Text) для комментариев и цитат.
- Кнопки: основная синяя заливка, радиус `--r-m`, высота 40–44px; второстепенная на заливке `--sunken` без рамки. Иконки lucide-react, 18–20px, только там, где без них хуже.
- Анимации короткие (150–300 мс): появление карточек, смена статуса ячейки, уведомление. Учитывать prefers-reduced-motion.

## Люди

Везде, где раньше был ID, показываем имя из справочника: `intern_name`, `mentor_name`, `person_name`, `name` в `/api/people`. Помощник `personName(name, id)` в `src/lib/format.ts` возвращает ID, если имени нет.

- Пару называем по стажёру: «Тимур Галиев», ниже мелко серым «наставник Андрей Котов». ID пары (P-03) в интерфейсе не нужен; ID людей показывать только в форме при выборе и мелко серым там, где нужно различить тёзок.
- С именем не согласуем глагол по роду: пишем «Новая анкета: Илья Морозов, 6-й месяц», а не «Илья прислал». Роль как подлежащее можно: «Стажёр ставит хорошие оценки».

## Запрещено

- Поясняющие предложения под заголовками секций и страниц.
- Подписи и пояснения под кнопками («Любая отметка уберёт сигнал…»).
- Строки о происхождении вывода («Фрагмент нашёл словарь…»), бейджи «формула», «разбор текста», «ИИ по тексту».
- Цепочки чисел «0,7 › 1,4 › 1,8», гантели, легенды из пяти пунктов, «начать с неё», плашки ID пар.
- Флажки массовых отметок, свёрнутые «ещё N сигналов на статус не влияют».
- Подчёркнутый текст, кроме ссылок. Жирное посреди фразы. Эмодзи.
- Больше одного вторичного цвета текста на элемент.
- Любой текст, который повторяет то, что видно на экране.

Если элемент хочется оставить, спроси себя, что HR потеряет без него. Если ответа нет, убрать.

## Шапка

Белая полоса на всю ширину, высота 64px.

```
[■ МГТС] Стажировки      Обзор   Сигналы (4)   Форма ↗            ● онлайн   ☾
```

- Слева знак: синий квадрат со скруглением 8px и белыми буквами «МГТС» шрифтом MTS Wide, рядом «Стажировки».
- Меню из трёх пунктов, активный подчёркнут синей чертой 2px.
- Справа зелёная точка связи (жёлтая — переподключаемся, серая — нет связи, с подсказкой при наведении) и одна кнопка-иконка темы.

## Обзор `/`

```
Стажировки                                         ноябрь · 6-й месяц

┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 4            │ │ 0            │ │ 1            │ │ 0 из 10      │
│ ● Пора       │ │ ● Присмот-   │ │ ● Всё ровно  │ │ анкет за     │
│   поговорить │ │   реться     │ │              │ │ 6-й месяц    │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘

┌───────────────────────────────────────────────────────────────────┐
│ Стажёр            1      2      3      4      5      6    Главное │
│ Илья Морозов     4,4    4,6    4,6    4,8    4,6     ·    Всё ровно │
│ наставник С. В.  4,5    4,8    4,8    4,5    4,8                    │
│ Кирилл Белов     4,6    4,4   [3,8]  [3,0]   —       ·   ● Перестал │
│ ...                                                       писать    │
└───────────────────────────────────────────────────────────────────┘
                                          ● стажёр  ● наставник
```

- Заголовок страницы MTS Wide, справа мелко текущий месяц сбора.
- Четыре карточки-итога: число крупно (MTS Wide), под ним точка статуса и подпись. Клик по статусной карточке фильтрует таблицу по статусу (повторный клик снимает фильтр).
- Таблица в белой карточке. Строка — пара: имя стажёра и под ним «наставник Имя Фамилия». Клетка месяца — две цифры друг под другом: оценка стажёра синим, наставника серым; заливка клетки по статусу месяца; нет анкеты — «—». Колонка месяца сбора без заливки, точка-пустышка, если анкет нет. Последняя колонка «Главное»: точка статуса и заголовок самого важного активного сигнала в одну-две строки или «Всё ровно».
- Строки идут в порядке: сначала «Пора поговорить», потом «Присмотреться», потом «Всё ровно»; внутри по числу открытых сигналов. Порядок не прыгает при живом обновлении до перезагрузки.
- Клик по строке открывает пару. Под таблицей одна строка легенды: «● стажёр ● наставник».
- Больше на обзоре ничего нет: ни очереди сигналов, ни последних анкет.
- Живое обновление: клетка, куда пришла анкета, получает синее кольцо и маленькую метку «новое», пока пару не открыли; статус меняется плавно; итоги перекатываются.
- 12 пар должны помещаться без поломок. На 1280×720 видны итоги и минимум 4 строки таблицы.

```

│  5 ─────■────■────■────■  наставник │ │ ● Стажёру хуже, чем видит │
│  4  ●                               │ │   наставник · 5-й месяц   │
│  3       ●────●────●────●  стажёр   │ │   В 5-м месяце стажёр 3,0,│
│     1    2    3    4    5    6      │ │   наставник 4,8.          │
└─────────────────────────────────────┘ │   «Наставник почти не     │
                                        │   отвечает…» — стажёр      │
┌─────────────────────────────────────┐ │   Что сделать: …          │
│ Комментарии                         │ │ [Подтвердилось] [Ложная]  │
│ 5-й месяц                           │ │                           │
│  Стажёр: «…»     Наставник: «…»     │ │ ● Следующий сигнал …      │
│ 4-й месяц ...                       │ └───────────────────────────┘
└─────────────────────────────────────┘
```

- Две колонки: слева график и комментарии, справа сигналы.
- График: две линии (стажёр синий, наставник серый), точки, заливка между ними `--series-gap`, подписи последних значений у концов линий, ось месяцев, месяц сбора пустой. Без статусов под осью и без лишних подписей.
- Сигналы: только активные открытые наверху, каждый — точка важности (оранжевая для высокой, жёлтая для средней, серая для низкой), заголовок, месяц, одна строка объяснения с цифрами, цитата шрифтом MTS Text с подсветкой фрагмента `--mark-bg`, строка «Что сделать: …», две кнопки. Отмеченные и старые сигналы — одной строкой «Разобранные: N» с раскрытием по клику.
- Комментарии по месяцам от свежего к старому: стажёр и наставник рядом, найденные фрагменты подсвечены. Пустой комментарий — серым «без комментария».
- Сверху справа переход к соседним парам стрелками с именами.

## Сигналы `/signals`

```
Сигналы                      [Открытые 14] [Разобранные] [Все]

┌───────────────────────────────────────────────────────────────────┐
│ ● Егор Данилов   Наставник недоволен, а стажёр не знает   5 мес ›│
│ ● Тимур Галиев   Стажёру хуже, чем видит наставник        5 мес ›│
│ ● Кирилл Белов   Стажёр не заполнил анкету                5 мес ›│
└───────────────────────────────────────────────────────────────────┘
```

- Одна строка на сигнал: точка важности, имя стажёра, заголовок сигнала, месяц, стрелка. Сначала высокая важность, потом свежие.
- Клик раскрывает строку на месте: объяснение, цитата, «Что сделать», кнопки «Подтвердилось» и «Ложная тревога», ссылка «Открыть пару». Раскрыта одна строка за раз.
- Фильтр один: сегменты «Открытые», «Разобранные», «Все» с числами. После отметки строка плавно уходит из «Открытых», внизу на 5 секунд плашка «Отмечено · Отменить».
- Пусто: «Все сигналы разобраны» и ничего больше.

## Форма `/form`

Мобильная, белая карточка на сером фоне, логотип МГТС сверху.

- Шаг 1: «Кто вы?» две большие кнопки «Стажёр» и «Наставник», затем список людей кнопками с именами (ID мелко серым), месяц подставлен автоматически и меняется в одном поле.
- Шаг 2: вопросы по одному блоку на вопрос, шкала 1–5 крупными кнопками (выбранная синяя), подписи краёв шкалы из анкеты под кнопками, поле комментария.
- Липкая кнопка «Отправить» снизу. Пропущенные вопросы при отправке подсвечиваются, страница прокручивается к первому.
- Готово: галочка, «Спасибо, анкета отправлена», кнопка «Заполнить ещё одну».
- Одна короткая строка про конфиденциальность над вопросами: «Ответы видит только HR программы.»

## QR `/form/qr`

Белая карточка по центру: крупный QR, под ним «Анкета стажировки МГТС» и адрес. Поле для адреса туннеля свёрнуто в «Изменить адрес». Если адрес локальный, вместо QR подсказка вставить адрес туннеля.

## Уведомление о новой анкете

Карточка в правом нижнем углу, тень `--shadow-high`: «Новая анкета», ниже «Илья Морозов, стажёр, 6-й месяц», если статус пары изменился — «● Всё ровно → ● Пора поговорить», кнопка «Открыть». Исчезает через 8 секунд.
