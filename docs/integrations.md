# Как анкеты попадают в дашборд

Опросы собираются в Google Формах или во встроенной форме платформы. Обновления дашборда идут через `/api/events`.

## Google Формы

### Доступ к API

1. В Google Cloud выберите проект и включите Google Forms API и Google Drive API. Создайте OAuth-клиент для веб-приложения. Для тестового приложения добавьте в список тестовых пользователей аккаунт владельца форм.
2. Для получения refresh token через [OAuth 2.0 Playground](https://developers.google.com/oauthplayground/) добавьте `https://developers.google.com/oauthplayground` в разрешённые URI перенаправления клиента. В настройках Playground выберите **Use your own OAuth credentials** и укажите Client ID и Client Secret своего клиента.
3. Запросите `https://www.googleapis.com/auth/drive.file` с доступом offline. Авторизуйтесь под аккаунтом, который будет владеть формами, и обменяйте код на токены. Сохраните **refresh token**. Тестовые внешние приложения могут потребовать повторной авторизации через семь дней.
4. Укажите в `.env` значения из примера. Сгенерируйте два отдельных случайных секрета командой `openssl rand -hex 32` для ключа HR и подписи ссылок. Перезапустите бэкенд. Для Docker после первой сборки выполните `docker compose up -d --force-recreate api`.

```dotenv
GOOGLE_FORMS_CLIENT_ID=
GOOGLE_FORMS_CLIENT_SECRET=
GOOGLE_FORMS_REFRESH_TOKEN=
GOOGLE_FORMS_HR_KEY=
GOOGLE_FORMS_LINK_SECRET=
GOOGLE_FORMS_POLL_SECONDS=15
```

[Авторизация Google OAuth 2.0](https://developers.google.com/identity/protocols/oauth2/web-server) · [Получение токена в OAuth Playground](https://developers.google.com/admob/api/v1/how-tos/playground)

### Создание форм и выдача ссылок

1. В дашборде откройте **Опросы**, введите ключ HR, укажите название потока и нажмите **Создать две формы**. В каждой базе можно настроить один поток. У стажёра 7 оценок и 2 открытых вопроса, у наставника 6 оценок и 2 открытых вопроса.
2. Для каждой формы откройте редактор Google и проверьте права респондентов. В меню **Ещё** выберите **Форма с предварительным заполнением**. В поле **Код приглашения** введите `MGTS-PREFILL`, оставьте остальные поля пустыми и нажмите **Получить ссылку**. Вставьте полную ссылку в карточку соответствующей роли в дашборде. Это одноразовая настройка каждой формы.
3. В разделе **Аналитика → Статус прохождения опросов** нажмите **Скопировать ссылку**. Сервер подставит код первого незаполненного месяца. Для наставника ссылка относится к одной паре. Google оставляет предзаполненный код видимым. ID, роль и период хранятся в платформе.
4. Отправьте ответ по личной ссылке. Сервер автоматически опросит Google Forms API. Для проверки нажмите **Проверить подключение** в разделе **Опросы**. Там видны статус синхронизации, пара и месяц принятого ответа. Повторная выдача того же ответа через API не меняет историю. Ответ по уже использованному приглашению отклоняется.

Публичный порт и туннель для Google не требуются. Если нужно опрашивать формы только вручную, установите `GOOGLE_FORMS_POLL_SECONDS=0`.

[Публикация и предварительное заполнение формы](https://support.google.com/docs/answer/2839588?hl=ru) · [Чтение ответов через Forms API](https://developers.google.com/workspace/forms/api/reference/rest/v1/forms.responses/list)

## Своя форма

Страница `/form` собирается из `GET /api/survey`. Список людей и следующий незаполненный месяц берутся из `GET /api/people`. Проверить без фронта:

```sh
data/send_demo.sh data/sample/demo/intern_S-01_m6.json
```

Тело запроса:

```json
{ "role": "intern", "person_id": "S-01", "month": 6, "source": "form",
  "answers": { "overall": 2, "tasks_interest": 2, "tasks_clarity": 3, "mentor_support": 3, "load": 3,
               "comment": "Третью неделю сижу без задач." } }
```

Для нового стажёра добавьте `mentor_id`, для нового наставника `intern_id`: пара создастся сама.

## Дополнительный импорт из Google Таблиц

Этот импорт предназначен для старых демонаборов. Основной сценарий выше читает ответы через OAuth. Для открытого CSV используйте только демонстрационные данные.

1. В форме: «Ответы» → «Связать с Таблицами». Вопросы называются так же, как в `survey/survey.json`, плюс «ID стажёра» и «Месяц стажировки».
2. В таблице: «Файл» → «Поделиться» → «Опубликовать в интернете». Выберите лист с ответами и формат CSV. Скопируйте ссылку, она кончается на `output=csv`.
3. Ссылки положите в `.env`: `GSHEET_CSV_URL_INTERN` и `GSHEET_CSV_URL_MENTOR`.
4. Забрать новые строки: `curl -X POST http://localhost:8000/api/sync/gsheet`. Или задайте `GSHEET_POLL_SECONDS=15`, и бэкенд будет забирать их сам.

Колонки узнаются по тексту вопроса, как при импорте Excel. Строки, которые уже есть в базе без изменений, пропускаются. Google обновляет опубликованную копию с задержкой до нескольких минут, поэтому для живого демо используйте Google Forms API или свою форму.

## Туннель для встроенной демоформы

Чтобы открыть встроенную форму с телефона, запустите `make up` и `make tunnel`. Туннель ведёт на ограниченный порт 8081. Дашборд HR открывается отдельно через порт 8080.
