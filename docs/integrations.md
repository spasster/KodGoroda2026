# Как анкеты попадают в дашборд

Три пути, все сходятся в одну базу. Новая анкета за тот же месяц заменяет прежнюю, поэтому повторная отправка ничего не ломает. Дашборд обновляется сам через `/api/events`.

| Путь | Адрес | Когда брать |
|---|---|---|
| Своя форма | `/form` во фронте, шлёт `POST /api/ingest` | основной путь на демо: работает в локальной сети без интернета |
| Google Формы | `POST /api/sync/gsheet` или фоновый опрос | внешний сервис без туннеля: бэкенд сам забирает ответы из опубликованной таблицы |
| Яндекс Формы | вебхук `POST /api/ingest/yandex` | только если есть публичный адрес с IPv6: Яндекс Формы шлют запросы только по IPv6 |

Про туннели. ngrok закрыт для российских IP. Трафик Cloudflare у российских провайдеров с июня 2025 года режется, поэтому `make tunnel` (cloudflared) нужно проверить в той сети, где будет показ. Путь через Google Таблицу туннеля не требует.

Поля, которые нужны в любой форме: роль (стажёр или наставник), ID человека, месяц стажировки и ответы на вопросы из `survey/survey.json`. Оценки можно слать строками: `"4"`, `"4 — скорее да"`.

## Своя форма

Страница `/form` собирается из `GET /api/survey`. Список людей и следующий незаполненный месяц берутся из `GET /api/people`. Проверить без фронта:

```sh
data/send_demo.sh data/sample/demo/intern_S-01_m6.json
```

Тело запроса:

```json
{ "role": "intern", "person_id": "S-01", "month": 6, "source": "form",
  "answers": { "overall": 2, "tasks_interest": 2, "tasks_clarity": 3, "mentor_support": 3, "load": 3,
               "comment": "Третью неделю сижу без задач." } }
```

Для нового стажёра добавьте `mentor_id`, для нового наставника `intern_id`: пара создастся сама.

## Яндекс Формы

1. Сделайте две формы: для стажёра и для наставника. Вопросы те же, что в `survey/survey.json`, плюс «ID стажёра» (или «ID наставника») и «Месяц стажировки».
2. Бэкенд должен быть доступен из интернета по IPv6: Яндекс Формы шлют запросы только по IPv6. Проще всего поднять туннель, см. ниже.
3. В форме откройте вкладку «Интеграции», выберите группу действий и нажмите «Запрос заданным методом».
4. Адрес: `https://<туннель>/api/ingest/yandex`. Метод: POST. Заголовок `Content-Type: application/json`.
5. Тело запроса: JSON ниже. Вместо `<…>` вставьте переменную «Ответ на вопрос» через значок справа от поля и выберите нужный вопрос. Для комментария включите фильтр JSON, иначе перенос строки в ответе сломает запрос.

Тело для формы стажёра:

```json
{
  "role": "intern",
  "person_id": "<Ответ на вопрос «ID стажёра»>",
  "month": "<Ответ на вопрос «Месяц стажировки»>",
  "overall": "<Ответ на вопрос «Как в целом проходит стажировка?»>",
  "tasks_interest": "<Ответ на вопрос «Насколько вам интересны задачи?»>",
  "tasks_clarity": "<Ответ на вопрос «Насколько понятно, что от вас ждут в задачах?»>",
  "mentor_support": "<Ответ на вопрос «Хватает ли вам помощи наставника?»>",
  "load": "<Ответ на вопрос «Насколько вам комфортна текущая нагрузка?»>",
  "comment": "<Ответ на вопрос «Что сейчас мешает или помогает в стажировке?», фильтр JSON>"
}
```

У наставника `"role": "mentor"`, `person_id` из вопроса «ID наставника» и ключи `overall`, `speed`, `independence`, `engagement`, `comment`.

Ключом может быть `id` вопроса или его текст: `"Как в целом проходит стажировка?": "4"` тоже сработает. Если поле `role` забыли, бэкенд определит роль по набору вопросов.

После настройки отправьте тестовый ответ. Ответ 200 значит, что анкета записана. Ответ 422 приходит с причиной на русском. Если причина «Тело запроса не JSON», уберите кавычки вокруг переменной с фильтром JSON: фильтр мог поставить их сам.

Что ещё знать:

- Формы ждут ответ 5 секунд. При ошибке 5xx или 404 они повторяют запрос до 7 раз за 30 минут. Повтор просто перезапишет ту же анкету.
- С `LLM_PROVIDER=openai` разбор комментария может занять дольше 5 секунд. Тогда Формы пришлют анкету повторно, на данных это не скажется.

Справка Яндекса: [запрос заданным методом](https://yandex.ru/support/forms/ru/send-request), [переменные](https://yandex.ru/support/forms/ru/vars).

## Google Формы

Google Формы не умеют слать вебхук без скриптов, поэтому бэкенд сам забирает таблицу ответов.

1. В форме: «Ответы» → «Связать с Таблицами». Вопросы называются так же, как в `survey/survey.json`, плюс «ID стажёра» и «Месяц стажировки».
2. В таблице: «Файл» → «Поделиться» → «Опубликовать в интернете». Выберите лист с ответами и формат CSV. Скопируйте ссылку, она кончается на `output=csv`.
3. Ссылки положите в `.env`: `GSHEET_CSV_URL_INTERN` и `GSHEET_CSV_URL_MENTOR`.
4. Забрать новые строки: `curl -X POST http://localhost:8000/api/sync/gsheet`. Или задайте `GSHEET_POLL_SECONDS=60`, и бэкенд будет забирать их сам.

Колонки узнаются по тексту вопроса, как при импорте Excel. Строки, которые уже есть в базе без изменений, пропускаются. Google обновляет опубликованную копию с задержкой до нескольких минут, поэтому на живом демо лучше своя форма или Яндекс.

## Туннель для телефона и вебхука

Ноутбук на площадке обычно за NAT. Туннель cloudflared даёт временный адрес `https://…trycloudflare.com` без регистрации.

```sh
make up                                         # всё в Docker на :8080
cloudflared tunnel --url http://localhost:8080  # или make tunnel
```

В выводе будет адрес вида `https://word-word-word.trycloudflare.com`. Форма для телефона: `<адрес>/form`. Вебхук для Яндекс Форм: `<адрес>/api/ingest/yandex`. Адрес меняется при каждом запуске туннеля, после перезапуска поправьте его в интеграции.

Если запущен только бэкенд, туннель ведите на него: `cloudflared tunnel --url http://localhost:8000`.
