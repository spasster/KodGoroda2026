# Как раздавать ежемесячные анкеты через внешний сервис

26.11. Вопрос: форма на каждого и каждый месяц, две общие формы с ручным вводом ID, или иначе.
Пометки: **[дока]** проверено по справке сегодня, **[память]** не нашёл в справке, проверить руками.

## Короткий ответ

Две общие Яндекс Формы (стажёр, наставник) и личные ссылки, где ID, роль и месяц приходят в скрытых вопросах через параметры ссылки. Ответ уходит вебхуком на `/api/ingest/yandex`. Запасной путь без публичного адреса: Google Форма + опрос таблицы. Форма на каждого не нужна: в личных формах нет API для их создания, а руками это 60 форм на 5 пар.

## Что говорит документация

### Яндекс Формы
1. **Предзаполнение через ссылку** [дока] https://yandex.ru/support/forms/ru/get-params
   - текст: `?<id_вопроса>=<текст>`, пробел заменяется на `+`, несколько полей через `&`;
   - варианты ответа и шкала: `<id_вопроса>=<id_ответа>`; длина адреса до 32 000 символов.
   - id вопроса задаётся в настройках вопроса, поле «Идентификатор вопроса» (https://yandex.ru/support/forms/ru/hidden-query).
2. **Скрытый вопрос** [дока] https://yandex.ru/support/forms/ru/hidden-query
   - вопрос «Короткий текст», включить «Скрытый вопрос», в «Идентификатор вопроса» вписать имя параметра;
   - пример из справки: `https://forms.yandex.ru/u/5e2ac2d…/?utm_source=site_name_1`. Адрес `/u/` значит, что пример про личную форму;
   - отвечающему вопрос не показывается. Нельзя одновременно ставить «Скрытый» и «Обязательный», иначе форма не отправится (справка, страницы конструктора вопросов).
3. **Вебхук «Запрос заданным методом»** [дока] https://yandex.ru/support/forms/ru/send-request
   - адрес, метод, заголовки, тело в JSON, значения подставляются переменными; запросы асинхронные;
   - **работает только по IPv6**, сеть Форм `2a02:6b8:c00::/40`;
   - таймаут 5 секунд; повтор при таймауте, сетевой ошибке, 5xx и 404: до 7 попыток за 30 минут; успех: 200/201/202; для дублей заголовок `x-delivery-id`;
   - текст с переносами строк в JSON ломается, нужен фильтр JSON.
4. **Переменные** [дока] https://yandex.ru/support/forms/ru/vars
   - «Ответ на вопрос», «ID ответа», «Время отправки ответа» (UTC), «Дата ответа», «ID формы», «GET-параметр» (по имени), «Все GET-параметры», фильтр JSON.
   - Значит ID и месяц можно взять даже без скрытого вопроса, переменной «GET-параметр». Но скрытый вопрос лучше: значение сохранится в ответах и в выгрузке Excel.
5. **API для создания форм** [дока] https://yandex.ru/support/forms/ru/api-ref/access, https://yandex.ru/support/forms/ru/api-ref/examples
   - только Формы для бизнеса (организация Яндекс 360 или Yandex Cloud), нужен `X-Org-Id`;
   - OAuth-приложение на oauth.yandex.ru, права `forms:write`, токен по ссылке `oauth.yandex.ru/authorize?response_type=token&client_id=…`;
   - `POST https://api.forms.yandex.net/v1/surveys/` создаёт форму, `GET /v1/surveys/{id}/answers` читает ответы. Метода копирования формы нет.
   - За полчаса с нуля не успеть: организация, приложение, токен, разбор схемы вопросов.
6. **Личные и бизнес-формы** [дока] https://yandex.ru/support/forms/ru/go-to-forms, https://yandex.ru/support/forms/ru/notifications
   - только в бизнесе: Трекер, Вики, общий доступ, вопросы «Люди/Отделы», API;
   - «Интеграции с сервисами Вики и Трекер доступны только пользователям Форм для бизнеса». Про HTTP-запрос в личных формах ограничений не названо. Наш `docs/integrations.md` исходит из того, что он есть [память, проверить за 2 минуты в конструкторе].

### Google Forms
7. **Предзаполненная ссылка** [дока] https://support.google.com/docs/answer/2839588 : «Ещё» → «Форма с предварительным заполнением» → «Получить ссылку». Формат `viewform?usp=pp_url&entry.123456=СТ-001` и отсутствие скрытых полей в справке не описаны [память]: поле видно и редактируется.
8. **«Опубликовать в интернете»** [дока] https://support.google.com/docs/answer/183965 : обновляется после изменений, «Это может занять несколько минут».
9. **`/export?format=csv&gid=…`** при доступе «все, у кого есть ссылка» отдаёт таблицу на момент запроса, без кеша публикации [память]. Наш `gsheet.py` ходит с `follow_redirects=True`, такая ссылка подойдёт в `GSHEET_CSV_URL_*`. Вебхука у Google Форм без Apps Script нет [память].

## Что важно в нашем коде

- `/api/ingest/yandex` **не открыт на порту 8081** (`frontend/nginx.conf`, блок `listen 81`: только `/form`, `/assets`, `GET /api/survey`, `GET /api/people`, `POST /api/ingest`). `make tunnel` смотрит на 8081, поэтому вебхук сейчас получит 404, и Яндекс будет повторять 30 минут. Нужен блок `location = /api/ingest/yandex { limit_except POST { deny all; } proxy_pass http://api:8000; }` на 81 и пересборка фронта. Туннель на 8080 не делать: наружу уйдут дашборд, импорт и `/api/admin/reset`.
- `flatten_yandex` поле `token` не переносит, подпись `tokens.py` для Яндекса не проверяется. Защита от подмены ID в ссылке сейчас только у своей `/form`. Если надо: одна строка, перенести `token` в `result`, и добавить в ссылку `&token=…` из `people[].token`.
- IPv6 у trycloudflare.com [память]: адреса Cloudflare обычно имеют AAAA. Проверить после запуска: `dig +short AAAA <адрес>.trycloudflare.com`. Пусто → вебхук не дойдёт.

## Сравнение вариантов

| | (а) форма на человека и месяц | (б) 2 формы, ID и месяц вводят руками | (в) 2 формы + личные ссылки со скрытыми ID/месяцем | (г) Google Форма + опрос таблицы |
|---|---|---|---|---|
| Настройка | 60 форм и 60 вебхуков руками, API только в бизнесе | 15 мин | 25–35 мин | 15–20 мин |
| Риск на демо | как (в) | туннель + IPv6 | туннель + IPv6 | нет входа снаружи, нужен только исходящий интернет к Google |
| Публичный адрес у нас | да | да | да | нет |
| Ошибки привязки | нет | высокие: чужой ID, не тот месяц | почти нет: ссылку выдаём мы; подмену закрывает токен | как (б), если без предзаполнения; с `entry.` видно и правится |
| Как выглядит для МГТС | хаос форм | привычно | как рассылка в Tabs: одна форма, ссылка на человека | привычно, выгрузка в таблицу |
| 50–100 стажёров | не масштабируется | масштабируется, ошибки растут | ссылки генерирует дашборд, формы те же | масштабируется, задержка опроса |

## Инструкция для сокомандника (30–40 минут)

1. forms.yandex.ru/admin → новая форма «Пульс-опрос стажёра». Вопросы из `survey/survey.json`: 7 шкал 1–5 и 2 «Длинный текст». У каждого вопроса в «Идентификатор вопроса» вписать `id` из json (`clarity`, `support`, `load`, `interest`, `growth`, `team`, `overall`, `difficulties`, `blockers`): бэкенд узнает ключ по id.
2. Добавить 3 скрытых «Коротких текста»: `role`, `person_id`, `month`. Галка «Скрытый вопрос», «Обязательный» не ставить.
3. Скопировать форму для наставника, поменять вопросы на наставничьи (6 шкал + 2 текста, id из json).
4. Шкала: если в теле придёт текст варианта («4» или «4 — скорее да»), бэкенд поймёт. Проверить первым тестовым ответом.
5. Наш ноутбук: добавить в `nginx.conf` блок для `/api/ingest/yandex` на 81 (см. выше), `make up`, `make tunnel`, записать адрес, `dig +short AAAA <адрес>`.
6. В форме «Интеграции» → «Запрос заданным методом»: `POST https://<адрес>/api/ingest/yandex`, заголовок `Content-Type: application/json`, тело:

```json
{
  "role": "<Ответ на вопрос role>",
  "person_id": "<Ответ на вопрос person_id>",
  "month": "<Ответ на вопрос month>",
  "clarity": "<Ответ на вопрос clarity>",
  "...": "так же для остальных шкал",
  "difficulties": <Ответ на вопрос difficulties + фильтр JSON, без кавычек, если фильтр их ставит>,
  "blockers": <то же>,
  "answer_id": "<ID ответа>",
  "submitted_at": "<Время отправки ответа>"
}
```

   `answer_id` бэкенд проигнорирует, он нужен только для логов. `submitted_at` ключом прочтётся, только если есть в `import_map`, иначе тоже игнор.
7. Личные ссылки (для 5+5 руками, позже генерировать в «Статусе прохождения опросов»):
   `https://forms.yandex.ru/u/<id_формы>/?role=intern&person_id=СТ-001&month=3`
8. Проверка бэкенда без Яндекса, через туннель:

```sh
curl -sS -X POST https://<адрес>/api/ingest/yandex -H 'Content-Type: application/json' \
  -d '{"role":"intern","person_id":"СТ-001","month":3,"clarity":"4","support":"2","load":"3","interest":"4","growth":"4","team":"5","overall":"3","difficulties":"тест","blockers":"тест"}'
```
   200 → анкета записана, дашборд обновится сам через `/api/events`. 422 → причина по-русски. Потом один настоящий ответ по личной ссылке с телефона.

## Запасной вариант

- Нет туннеля или IPv6: Google Форма с теми же вопросами + поля «ID стажера» и «Месяц стажировки» (предзаполненная ссылка), таблица с доступом по ссылке, в `.env` `GSHEET_CSV_URL_INTERN=https://docs.google.com/spreadsheets/d/<id>/export?format=csv&gid=<gid>`, `GSHEET_POLL_SECONDS=15`. Нужен только исходящий интернет. Проверка: `curl -X POST http://localhost:8080/api/sync/gsheet`.
- Нет интернета совсем: своя `/form` по локальной сети и заранее записанный скринкаст сценария с Яндексом. Честно сказать, что это запись (слайд 17).

## Фраза жюри про масштабирование

«Форм две на всю программу, меняется только ссылка: ID и месяц в ней подставляет дашборд, поэтому на 100 стажёров это те же две формы и 100 ссылок в рассылке, а ошибиться с ID человек не может».
